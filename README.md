
# 🎬 CrisFlix

Plataforma de streaming inspirada na Netflix, desenvolvida para exibição de filmes, séries e conteúdos em uma interface moderna, rápida e responsiva.

🔗 **Acesse o projeto:**
👉 [Acssar](https://crissflix.vercel.app/)

---

## 🚀 Funcionalidades

* 📺 Listagem de canais
* 🎨 Interface estilo Netflix
* 🖼️ Cards com imagens dinâmicas
* ⚡ Alta performance com Vite

---

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Vite
* React
* Node.js
* Vercel

## ⚙️ Como rodar localmente

```bash
git clone https://github.com/cthelegend/crisflix-site-filmes.git
cd crisflix-site-filmes
npm install
npm run dev
```

Acesse: [http://localhost:5173](http://localhost:5173)
